# Simulador de Circuitos CD — ACE

Interfaz gráfica Fase 3, desarrollada con CustomTkinter y Matplotlib.
Incluye parámetros editables, validación, tarjetas de resultados, tabla
comparativa y gráficas de voltaje y potencia.

## Lenguaje usado

- Python 3.10 o posterior
- Tkinter

## Instalación y ejecución

Clonar el repositorio y entre en la carpeta del proyecto:

```powershell
git clone https://github.com/william12-rtz/Fase3_ACE.git
cd Fase3_ACE
```

Crear un entorno virtual, instale las dependencias y ejecute la aplicación:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python app.py
```

Si PowerShell impide activar el entorno virtual, puede ejecutar el proyecto
directamente con:

```powershell
python -m pip install -r requirements.txt
python app.py
```
